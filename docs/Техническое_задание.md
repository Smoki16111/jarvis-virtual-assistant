# Техническое задание проекта «J.A.R.V.I.S.»

## 1. Цель и задачи проекта
**Цель**: разработать веб-приложение виртуального помощника, способного отвечать на текстовые и голосовые команды, предоставлять справочную информацию (погода, время, шутки) и имитировать диалог.

**Задачи**:
- Создать одностраничное веб-приложение (SPA) с чат-интерфейсом.
- Реализовать текстовый ввод и вывод ответов.
- Подключить внешние API (OpenWeatherMap) для получения погоды.
- Внедрить Web Speech API для голосового ввода и синтеза речи.
- Обеспечить адаптивный дизайн под мобильные устройства.

## 2. Целевая аудитория
- Обычные пользователи, желающие быстро получить погоду или развлечься.
- Студенты и энтузиасты, изучающие веб-разработку и API.

## 3. Проблема, которую решает приложение
Отсутствие простого, не требующего установки помощника в браузере, способного работать на любых устройствах без авторизации. J.A.R.V.I.S. закрывает потребность в быстрых голосовых запросах прямо на веб-странице.

## 4. Аналоги
- **Google Assistant / Siri** — мощные, но требуют установки или привязки к ОС.
- **Чат-боты в Telegram** — функциональны, но ограничены мессенджером.
- **Jarvis на Python** — требует локального запуска, нет веб-доступа.

Преимущество нашего приложения: кроссплатформенный доступ через браузер, минимальные требования, расширяемость.

## 5. Описание работы приложения
**Тип проекта**: веб-приложение (Single Page Application).  
**Стек технологий**:
- HTML5, CSS3, JavaScript (ES6+)
- Сборка: пока без фреймворков (чистый JS), возможно добавление Webpack в будущем.
- API: OpenWeatherMap, возможно другие бесплатные API.
- Голос: Web Speech API (SpeechRecognition и SpeechSynthesis).

**Сценарий использования**:
1. Пользователь открывает страницу, видит приветствие J.A.R.V.I.S.
2. Вводит текстовый запрос или нажимает кнопку голосового ввода.
3. Помощник анализирует команду и выдаёт ответ в чат-области.
4. При команде «погода» отправляется запрос к API и возвращается текущая температура.
5. Речь синтезируется и воспроизводится через динамики.
