# J.A.R.V.I.S. — Виртуальный помощник

**J.A.R.V.I.S.** — веб-приложение, имитирующее интеллектуального голосового ассистента. Пользователь может общаться с помощником через текстовый или голосовой ввод, получая ответы, прогноз погоды и другую полезную информацию.
